## 🗺️ Roadmap de Desarrollo

El desarrollo del proyecto se organizó en las siguientes etapas:

1. **Etapa 1 - Estructura base**:  
   - Creación del repositorio.  
   - Estructura de carpetas y primeras páginas (`index.html`, `login.html`, `registro.html`).  

2. **Etapa 2 - Módulos y navegación**:  
   - Implementación del navbar dinámico con JavaScript.  
   - Ruteo entre páginas y control de sesión con `localStorage`.

3. **Etapa 3 - Carga dinámica de productos**:  
   - Lectura de productos desde archivo `productos.json`.  
   - Renderizado automático de cards con `fetch` y JS.  

4. **Etapa 4 - Funcionalidades clave**:  
   - Agregado de carrito de compras con persistencia por usuario.  
   - Página de historial de compras.  
   - Estilización con CSS y mejoras visuales.  

5. **Etapa Final - Mejora general**:  
   - Navbar reutilizable con barra de búsqueda y filtros por categoría.  
   - Modo oscuro, mejoras en la estructura del código y separación por módulos.  
   - Publicación en Vercel y documentación final.

## ⚙️ Tecnologías Utilizadas

- **HTML5 & CSS3** – estructura y diseño.  
- **JavaScript Vanilla** – lógica de interacción.  
- **LocalStorage** – manejo de sesiones y persistencia del carrito.  
- **Vercel** – para el despliegue público.  
- **GitHub** – control de versiones y colaboración.  
- **Fetch API** – lectura dinámica de archivos JSON.

## 🔧 Mejora Significativa

Se implementó una **barra de búsqueda dinámica con filtros por categoría**, integrada en un `navbar.html` cargado mediante `fetch`. Esto permite:

- Reutilizar el navbar en todas las páginas.  
- Mejorar la experiencia del usuario con búsqueda rápida.  
- Mantener la UI sincronizada con el estado de sesión.  
- Aplicar filtrado en vivo sin recargar la página.

Además, se añadió un **modo oscuro**, mejoras de accesibilidad y un diseño más consistente.
